# EvalShield 术语表 v0

生成时间：2026-04-21。
作用：统一核心术语写法，避免后续文档轻微漂移。

## 术语

### Benchmark run

固定写法：

- `benchmark run`

含义：

- 一次具体评测执行及其产物集合

不要替换成：

- eval session
- benchmark job
- review attempt

### PR review benchmark

固定写法：

- `PR review benchmark`

含义：

- 面向 PR review / code review agent 的 benchmark 类型

### PR-review-agent

固定写法：

- `PR-review-agent`

含义：

- 在 PR review benchmark 中被评测的 reviewer agent

### Run trust

固定写法：

- `run trust`

含义：

- 一次 benchmark run 的结果可信度

注意：

- 它不是模型整体能力
- 它也不是通用 agent 安全性

### Canonical bundle

固定写法：

- `canonical bundle`

含义：

- EvalShield 内部的标准化 truth-source artifact 表示

### Canonical contract

固定写法：

- `canonical contract`

含义：

- versioned、digest-addressed 的对象契约定义

### Detector finding

固定写法：

- `detector finding`

含义：

- detector family 输出的一条结构化发现

### Detector family

固定写法：

- `detector family`

含义：

- 同类 trust-failure 检测器集合

v1 只允许三类：

- leakage
- exploit
- replay mismatch

### Trust verdict

固定写法：

- `trust verdict`

含义：

- 机器权威输出：`trusted | suspect | invalid`

### EvidenceRef

固定写法：

- `EvidenceRef`

含义：

- 指向具体 supporting evidence 的结构化引用

### Pointer

固定写法：

- `pointer`

含义：

- `EvidenceRef` 中的机器可解析定位字符串

### Replay bundle

固定写法：

- `replay bundle`

含义：

- replay 尝试的结构化元数据与引用集合

### Structural replay

固定写法：

- `structural replay`

含义：

- 验证 run 结构与证据链可重建

### Behavioral replay

固定写法：

- `behavioral replay`

含义：

- 尝试验证 findings / verdict / review behavior 的相似性

注意：

- v1 不把它当硬承诺

### Casebook

固定写法：

- `casebook`

含义：

- 围绕 suspect / invalid runs 组织的结构化案例集

### Case record

固定写法：

- `case record`

含义：

- casebook 的原子结构化单位

### Exemplar

固定写法：

- `exemplar`

含义：

- v1 第一套固定 fixture 形态，用于收敛 adapter 设计

### Artifact ingest

固定写法：

- `artifact ingest`

含义：

- 从外部 benchmark 产物进入系统、并进入 canonical normalization 的阶段

## 术语使用规则

- 写设计文档时，优先使用本术语表中的固定写法
- 若需要中文解释，允许在首次出现时写：
  - `run trust（单次 run 的可信度）`
  - `canonical bundle（标准化真相包）`
- 不要在不同文档里为同一对象发明多个名字

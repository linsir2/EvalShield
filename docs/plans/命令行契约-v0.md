# CLI 契约 v0

生成时间：2026-04-21。
适用范围：EvalShield v1。

## 目的

这份文档定义 EvalShield v1 CLI 的最小行为。

## Exit Codes

- `0` = trusted
- `10` = suspect
- `20` = invalid
- `30` = input / contract error
- `40` = internal detector or replay failure

## 最小 Summary 输出

CLI summary 至少包含：

- verdict
- primary reasons
- report path
- replay bundle path

## 明确不做

- rich TUI
- dashboard 行为
- live streaming workflow UI
